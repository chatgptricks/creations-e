# Project visual covers

Use the 1600 × 1100 WebP files on the portfolio; editable, self-contained SVG versions are retained alongside them. These are art-directed project covers, not product screenshots, except for the clearly visible USS Sentient application capture within its cover.

- `engine.webp` / `engine.svg`: original sculpture, coral and orbits template illustrations from Engine (`21 Engine/public/template-editor`). Typography, layered poster staging, selection handles and cursor are new cover artwork.
- `sentient.webp` / `sentient.svg`: exact Sentient symbol from `22 Sentient Website Astra/site/public/assets/sentient-symbol.svg`; chrome extrusion, lime orbital field and layout are new cover artwork, using the project's established identity.
- `uss.webp` / `uss.svg`: actual browser capture of the public USS Sentient application at `https://chatgptricks.github.io/uss-sentient/`, made October 17, 2026. The original capture is `uss-live.jpg`. The surrounding title and orbital treatment are new cover artwork.
- `story.webp` / `story.svg`: original Cuentacuentos watercolor fox, rabbit and dragon from the existing portfolio `assets/story-art.png` (the project's character atlas). The open-book staging and typography are new cover artwork.

SVGs were visually checked in the browser. WebP exports were separately inspected at their full 1600 × 1100 resolution. No private screens, data or credentials are included.
